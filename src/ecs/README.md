# ECS Модуль

## Зависимости
- [entt](https://github.com/skypjack/entt) — Entity Component System

## Описание
Модуль ECS реализует менеджер сущностей, компоненты и системы для управления объектами движка.

## Использование
- Подключите ECSManager, Components, Systems в нужных частях проекта.
- Добавляйте компоненты Position, Velocity и свои собственные.
- Используйте системы для обновления состояния объектов.
