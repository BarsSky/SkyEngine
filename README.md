# Твердь Машина

## Описание

В репозитории представлен развивающийся проект 3D движка цель которого изучение API взаимодействия с видеокартой - [Vulkan](https://vulkan.org/).

Проект поддерживает несколько платформ ОС:
  
  * Линукс (образы основанные на Debian)
  * Windows (в частности поддерживаются компиляторы MSVC и MinGW)

## Используемые зависимости

- Движок использует реализацию [ImGui](https://github.com/ocornut/imgui?ysclid=m7ozlnpqlq654568493) для формирования пользовательского интерфейса 
- Движок основан и разработан только для взаимодействия с [API Vulkan](https://vulkan.org/)
- Для кроссплатформенного взаимодействия с операционной системой используется библиотека [GLFW](https://github.com/glfw/glfw?ysclid=m7ozniweeq589521415) 
- Для текстур и изображений используется библиотека [STB](https://github.com/nothings/stb.git)
- Как альтернатива кроссплатформенной библиотеки движок имеет возможность интеграции в библиотеку [QT 5.14](https://www.qt.io/)
- Для изучения API Vulkan используются материалы представленные в [Vulkan Examples](https://github.com/SaschaWillems/Vulkan)

## Возможности
    Движок способен отображать объекты следующих расширений:
        - GLTF/GLB
        - OBJ
        - Построение объекта по массивам вершин и индексов
    Реализованы следующие модели:
        - Отрисовка 3D 2D объектов с текстурами
        - Формирования частиц с помощью процессора или видеокарты
        - Отрисовка текста 
        - Отрисовка объемных линий по массиву вершин, для изменения типа линии используется геометрический шейдер
