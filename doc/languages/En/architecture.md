# Architecture Overview

This document describes the high-level architecture of the SkyEngineBase library.

## Main Components
- **Core Engine**: Handles initialization, main loop, and resource management.
- **Rendering**: Vulkan-based renderer, pipeline management, and shaders.
- **Scene & Objects**: Scene graph, 3D/2D objects, primitives, and models.
- **Camera System**: Camera classes for different perspectives and controls.
- **UI & Overlays**: ImGui integration, text overlays, and custom UI forms.
- **Platform Abstraction**: Cross-platform windowing (GLFW/Qt), input, and OS interaction.
