# Modules Overview

This document briefly describes the main modules and directories in SkyEngineBase.

## lib/libSkyEngine/
- Core engine source files, main classes, and logic.
- Subfolders:
  - **Camera/**: Camera and view-related classes.
  - **extension/**: Optional or experimental features.
  - **include/**: Public headers for external use.

## dependencies/
- Third-party libraries (ImGui, STB, etc.)

## examples/
- Example projects demonstrating engine usage.

## tests/
- Test projects for different features and integration (e.g., test_1, test_2).

## tools/
- Utility programs and monitoring tools.
