# Обзор архитектуры

В этом документе описывается высокоуровневая архитектура библиотеки SkyEngineBase.

## Основные компоненты
- **Ядро движка**: инициализация, главный цикл, управление ресурсами.
- **Рендеринг**: рендерер на Vulkan, управление пайплайнами и шейдерами.
- **Сцена и объекты**: граф сцены, 3D/2D объекты, примитивы и модели.
- **Система камер**: классы камер для разных видов и управления.
- **UI и оверлеи**: интеграция ImGui, текстовые оверлеи, пользовательские формы.
- **Платформенная абстракция**: кроссплатформенные окна (GLFW/Qt), ввод, взаимодействие с ОС.
